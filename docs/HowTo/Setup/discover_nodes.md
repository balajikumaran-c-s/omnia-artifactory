# Discover nodes using OME

Discovery is now an independently invoked deployment domain with
project-scoped inputs and outputs. Use [Discover nodes using
OME](../discovery/discover_nodes.md) for the current prerequisites, supported
OME static groups, iDRAC hostname planning, input paths, CLI commands,
verification, handoff, and troubleshooting.

The current workflow runs from `src/main` with
`./omnia.sh --run discovery`. The former omnia_core-container command and the
shared `/opt/omnia/input/<project>/` paths are obsolete.
