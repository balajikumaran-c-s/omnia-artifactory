# local_repo_config.yml is retired

The current Repo Manager source stages `repo_manager_config.yml` and
`repo_manager_endpoint_config.yml`; it does not stage `local_repo_config.yml`.

Use the [Repo Manager configuration](repo_manager_config.md) for repository and
registry mappings and the
[Repo Manager endpoint configuration](repo_manager_endpoint_config.md) for the
Pulp service address.
