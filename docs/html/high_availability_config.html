Parameter

Details

service_k8s_cluster_ha

list / elements=dict / required

High Availability (HA) configuration for Kubernetes (K8s) service clusters. The current provisioning path consumes the first entry and generates kube-vip configuration from its virtual IP address.

cluster_name

string

Identifies the intended service cluster. Keep this value aligned with omnia_config.yml. The current provisioning role does not use the name to select an HA entry.

enable_k8s_ha

boolean

Possible values: true or false

Runtime default: false when omitted.

Set this value to true for the supported HA configuration. The current provisioning role reads the value but does not use it to disable kube-vip generation.

virtual_ip_address

string / required

This is a mandatory and user-configurable parameter.

Captures the virtual IP address for the K8s service node HA setup. Ensure that the virtual_ip_address does not belong to the dynamic_range mentioned in the network_spec.yml.

Sample value: 172.16.107.1

The current input validator does not verify the VIP subnet or detect conflicts with node, OIM, DHCP, or MetalLB addresses. Perform these checks before provisioning.
